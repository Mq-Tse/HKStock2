# 港股新股收益追踪

一个本地运行的港股 IPO 数据工具：收录 **2010 年至今**港股新股，提供暗盘、上市首日与至今收益的查询、排名与可视化。

后端 FastAPI + SQLite，前端为不依赖构建工具的原生 HTML/CSS/JS。

---

## 功能特性

### 列表页

- 按股票名称、代码搜索，按上市年份筛选
- 按暗盘状态、暗盘收益有无、自选收藏筛选
- 多列排序（上市日期、发行价、暗盘、首日、最新价、至今收益等）
- 分页浏览，支持每页 50 / 100 / 200 / 500 条
- 收藏自选（`localStorage` 持久化，不涉及账号）
- 一键导出当前筛选结果为 CSV（带 BOM，Excel 直接打开不乱码）
- 同一代码被多家公司复用上市时自动折叠，展开可查看历史实体

### 收益榜单

三张独立榜单，各含 Top 20 与 Bottom 20：

| 榜单 | 口径 |
| --- | --- |
| 暗盘收益排名 | 暗盘收盘价 / 发行价 − 1 |
| 首日收益排名 | 首日收盘价 / 发行价 − 1 |
| 至今收益排名 | 最新价 / 发行价 − 1（复权优先） |

榜单跟随页面筛选条件实时重排，不受分页影响；同一股票仅保留最新上市实体。

### 散点图

暗盘收益 vs 首日收益，用于判断暗盘走势对首日表现的预测能力：

- 展示皮尔逊相关系数、线性回归趋势线与斜率
- 按上市年份分色，并给出各年份桶的独立相关系数
- 坐标轴按 1%–99% 分位裁剪，隐藏极端值并标注数量，避免少数异常点压扁整体分布
- 点击任意点跳转个股详情

### 个股详情

- 分时 / 日 K / 周 K / 月 K 切换
- K 线图上标注发行价（实线）与首日收盘价（虚线）
- 暗盘数据附来源链接，可回溯核对
- 一键加入多标的对比

### 多标的对比

`/compare?codes=00700,09988` 最多同屏对比 6 只，每只显示关键指标与近 200 日 K 线；单只加载失败不影响其他。

## 数据说明

### 覆盖范围

2010-01-01 至今的港股新股，含已退市标的。

### 指标口径

| 字段 | 含义 |
| --- | --- |
| `issue_price` | 发行价（港元） |
| `grey_return` | 暗盘收益 = 暗盘收盘价 / 发行价 − 1 |
| `first_day_return` | 首日收益 = 首日收盘价 / 发行价 − 1 |
| `to_date_return` | 至今收益（未复权）= 最新价 / 发行价 − 1 |
| `to_date_return_adj` | 至今收益（复权）= (复权最新价 / 复权首日收盘) × (首日收盘 / 发行价) − 1 |

复权价采用腾讯前复权序列（及东方财富 `fqt=2` 交叉校验），用于剔除送股、拆股、供股对长期收益的干扰。

### 暗盘状态

| 状态 | 含义 |
| --- | --- |
| `ok` | 有暗盘交易，已获取收盘价 |
| `not_found` | 应有暗盘，但各数据源均未收录 |
| `inapplicable` | 不适用暗盘（介绍上市、全配售等） |

### 数据来源

| 用途 | 来源 |
| --- | --- |
| 新股列表、发行价、行情快照、K 线 | 东方财富 |
| 复权价锚点、退市股日 K | 腾讯财经 |
| 暗盘收盘价 | AAStocks、格隆汇、辉立交易场（含 PDF / OCR 解析） |

所有请求均为公开页面与公开接口，不涉及账号、密钥或付费数据。

### 刷新策略

服务启动时自动触发一次后台刷新，各数据按 TTL 增量更新：

| 数据 | 缓存时长 |
| --- | --- |
| 新股列表 | 6 小时 |
| 实时行情 | 15 分钟（停牌标的 30 天） |
| 暗盘（未获取到） | 24 小时重试 |
| 历史最低 / 最高价 | 24 小时 |

也可在页面上点击「刷新数据」，或调用 `POST /api/refresh` 强制刷新。

## 快速开始

要求 Python 3.11 及以上。

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```

打开 http://127.0.0.1:8000

数据库默认读取 `data/hk_ipo.db`，如需指向其他文件：

```bash
set HKSTOCK_DB=D:\path\to\hk_ipo.db        # Windows
export HKSTOCK_DB=/path/to/hk_ipo.db       # macOS / Linux
```

> 列表页散点图通过 CDN 加载 ECharts 5.5.1，首次打开需要联网；其余页面与图表均使用本地资源。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/ipos` | 新股列表，支持 `q`（名称/代码）、`year`、`sort`、`order` 参数 |
| GET | `/api/stock/{code}` | 单只股票详情与全部收益指标 |
| GET | `/api/stock/{code}/kline` | K 线数据，`period` 取 `intraday` / `day` / `week` / `month` |
| POST | `/api/refresh` | 触发后台刷新，返回 202 |
| GET | `/api/refresh/status` | 刷新进度、已完成数量、错误明细 |

页面路由：`/`、`/stock/{code}`、`/compare?codes=00005,09988`。

K 线接口按周期缓存（分时 30 秒、日线 5 分钟、周线 10 分钟、月线 15 分钟）。

## 已知限制

- **复权覆盖不完整**：约 96% 的新股可取到复权序列。深度供股或长期停牌标的，腾讯与东方财富的复权末值同为负值，无法计算，页面会标注「复权数据不可用」并回退未复权收益。
- **暗盘数据非官方**：来自第三方公开来源，个别标的可能缺失或存在单位误差，已对明显异常值做置空处理。
- **实时行情有延迟**：行情快照按 15 分钟缓存，不适用于短线交易决策。
- **仅供研究**：本项目用于数据分析与学习，不构成任何投资建议。
